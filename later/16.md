## 81. Алгоритм

Ф. На это счет у нас есть специальный алгоритм. Берем, например, карту личности. В ней есть клетки Каждая клетка – способность, она же потребность. Заполняем карту для личности и для задачи (семейства задач)

Для задачи в каждую клетку ставим одно из трех слов

Очень надо

Категорически нельзя

Не влияет

В карте личности в каждую клетку ставим одно из трех значений

Есть и много

Нет совсем

Есть, но не много

Теперь сопоставляем слова в двух картах (личности и задачи) в одноименной клетке

Возможны девять вариантов (поставлю на только те, что влияют

|  | запрещено | Не влияет | Очень надо |
| Нет совсем |  |  | Неудача |
| Есть |  |  |  |
| Есть много | Катастрофа |  | Успех |

Худшая комбинация это когда есть много и категорически запрещено. Это катастрофа.

Изобретатель решил, что заправочный комплекс морально устарел.

Как прилетает самолет заправляться – так комплекс в разобранном виде. А летчику надо побыстрее.

Тогда ваш продукт будет плохого качества.
